# 회귀 테스트 항목

`tests/recovery.mjs`의 항목 번호가 무엇을 확인하는지 구간별로 적는다. 실행 방법과 결과 읽기는 [03_DEV_SETUP 4.4](03_DEV_SETUP.md#44-회귀-테스트)를 본다.

> 이 문서는 `node tests/cases-doc.mjs`가 만든다. 손으로 고치지 않는다. 테스트를 고친 뒤 다시 만들지 않으면 회귀 테스트 마지막의 문서 일치 항목이 FAIL이 된다.

- 설명은 테스트가 출력하는 문구 그대로다. 한 번호에 판정이 여러 개면 ` / `로 잇는다.
- 글자는 구간 표시일 뿐 뜻은 없다. L(락 대기 제한·로그 정리)과 G(시즌 스케줄러·관리 API)는 두 구간에 있으므로 구간과 함께 읽는다.
- 번호는 추가된 순서라 실행 순서와 다를 수 있다.

| J7 | 전 시즌 제재 해제: 진행 중 시즌에 재반영 |
| J8 | 해제 거부: 없는 제재 1604, FINALIZING·DELIVERING 시즌 1603 / FINALIZING 중 등록은 기록만 (표시 없음, Redis 키 없음) |
| J9 | FINALIZING 중(검수 뒤) 제재: DELIVERING 전이가 entry·Top N에 sanctioned, 순위 유지 |
| J10 | DELIVERING 이후 등록: 즉시 표시(순위·PENDING 유지), 분리된 시즌은 Top N만, 전 시즌 제재는 DELIVERING 시즌에만 (SETTLED 제외) |
| J11 | 복구 잡: 재구축 전에 제외 집합을 DB에 맞춤 (DB에만 있는 제재 SADD·제외, Redis에만 남은 제재 SREM·재반영) |
| J12 | Redis 장애 중 등록: DB 반영·redisSynced false, 복구 잡이 제외 집합·순위표를 맞춤 |
| J13 | 감사 로그: 등록(시즌 상태)·해제(지운 행), 거부도 기록 |
